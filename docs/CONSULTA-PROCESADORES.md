# Consulta a proveedores de pago (borrador)

Objetivo: obtener **respuesta escrita** de si admiten este modelo antes de construir nada. Se envía por el canal de ventas/cumplimiento de cada proveedor, no por soporte general.

Antes de enviar:
1. Rellena los campos entre corchetes con datos reales. No inventes cifras: si aún no las tienes, di que son estimaciones.
2. Describe solo lo que existe o está **previsto**. Los controles de abajo (verificación de edad, de vendedores, moderación) **aún no están implementados**; el texto dice "previstos". Si se envía antes de retirar de las páginas legales las afirmaciones que hoy no se cumplen, el proveedor verá una web que promete más de lo que hace.
3. Guarda todas las respuestas (correo completo, con fecha). Sin respuesta escrita no cuenta como confirmación.

Proveedores a consultar (hay que verificar cada uno; **no he comprobado que ninguno acepte este modelo**):
- Stripe (Connect). Sus políticas públicas restringen contenido adulto y artículos de orientación sexual con aprobación previa.
- Adyen for Platforms.
- Proveedores europeos de pagos para marketplaces (p. ej. Mangopay, Lemonway), que suelen tener listas de actividades prohibidas.
- Proveedores especializados en alto riesgo / adulto (p. ej. CCBill, Segpay): suelen estar orientados a contenido digital y suscripciones, no a mercados con custodia de fondos. Preguntar si lo cubren.
